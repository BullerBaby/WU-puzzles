Load your own game (paste JSON)

Paste a game as JSON below, then click Load game. The easiest start is Use current as template: it dumps the game you're viewing into the box so you can edit it. Custom games are saved in your browser (localStorage) and added to the dropdown. Single game or a JSON array of games both work. Required fields: title, board, warbands (one of the registered ids — fighter stats and abilities come from there), steps. To create one from a description or photo using an AI, see the authoring guide — it has a ready-to-paste prompt that converts plain English (or a board photo) into valid JSON.
